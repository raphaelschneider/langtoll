# What's New — 1.0.5

Paste per localization into App Store Connect → 1.0.5 → "What's New in This Version".
This version follows 1.0.4 within days (2026-10-04): a first screen that shows the
app instead of describing it, every Plus benefit on the plan screen, notifications
asked only where the app explains why, and a kinder first fare.
